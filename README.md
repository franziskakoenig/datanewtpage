# datanewt homepage

The public one-page homepage for datanewt, served with GitHub Pages.

The site uses the approved blue-circle newt, Noto Sans served from this repository, and light/dark themes. It has no external font service, analytics, cookies, forms or persistent theme storage.

This repository contains only public website assets. Internal business documents and branding development files are not part of this site.

GitHub Pages deploys from the workflow in .github/workflows/pages.yml when main changes. The workflow stages only index.html, homepage.css, app.js and assets/.

## Local preview

Run python3 -m http.server 8080 from the repository folder, then open http://localhost:8080/.

Contact information, app links and finalized legal information will be added later. No placeholder contact or legal pages are published.

## Fonts

Noto Sans Regular, Semibold and Bold accompany the site. Their license is included at assets/fonts/LICENSE.txt.
